### EXAKTE MATHEMATIK IM HINTERGRUND (Unbedingt beibehalten!):
- **Eval-Breach (+1.00% Move):** Wenn eine Eval ihren Max-Drawdown erreicht, wird sie durch die Live-Equity automatisch geschlossen (Hard-Breach). Es fällt bis zum Breach-Punkt also NUR die einfache Eröffnungsgebühr (`Open_Fee = Maker_oder_Taker_Entry_Fee`) an, KEINE Closing-Fee!
  - `Eval_Max_DD_USD = Eval_Size * (Max_DD_Pct / 100)`
  - `Eval_Pos_USD = Eval_Max_DD_USD / ((SL_Move_Pct / 100) + Eval_Open_Fee)`
- **Eval-Pass (~ -3.00% Move bis +9% Netto-Target):** Zum Bestehen muss die Position regulär geschlossen werden. Hier fällt die volle Round-Trip-Gebühr (`Eval_RT_Fee = Open_Fee + Close_Fee`) an:
  - `Eval_Target_USD = Eval_Size * (Target_Pct / 100)`
  - `Eval_Fee_RT_USD = Eval_Pos_USD * Eval_RT_Fee`
  - `TP_Move_Pct_Eval = ((Eval_Target_USD + Eval_Fee_RT_USD) / Eval_Pos_USD) * 100`
  - `Max_TP_Move_Pct = Maximum aus TP_Move_Pct von Eval #1 und Eval #2`
- **Funded-Account (Gegenposition):** Darf niemals breachen und wird auf beiden Seiten regulär geschlossen (volle `Funded_RT_Fee`):
  - `Total_Eval_Costs = (Cost_Eval_1 + Cost_Eval_2) * (1 - Rabatt_Pct / 100)`
  - `Needed_Net_Payout = Total_Eval_Costs + Over_Hedge_Extra_USD`
  - `Needed_Gross_Profit = Needed_Net_Payout / (Funded_Split_Pct / 100)`
  - `Funded_Pos_USD = Needed_Gross_Profit / ((SL_Move_Pct / 100) - Funded_RT_Fee)`
  - `Funded_Loss_At_Eval_Win = Funded_Pos_USD * ((Max_TP_Move_Pct / 100) + Funded_RT_Fee)`
  - `Funded_Remaining_Buffer = Funded_Max_DD_USD - Funded_Loss_At_Eval_Win`
  - **Sicherheits-SL für Funded:** Falls `Funded_Remaining_Buffer < 50 USD`, setze den SL-Kurs des Funded-Accounts automatisch auf 95% seines Max-Drawdowns (Slippage-Schutz).
